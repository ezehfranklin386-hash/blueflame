# Blue Flame Gas Supply LTD Website

A static website for Blue Flame Gas Supply Limited - LPG gas delivery service in Lagos.

## Hosting on GitHub Pages

### Option 1: Automatic (GitHub Web Interface)
1. Create a GitHub repository named `[your-username].github.io`
2. Upload all files from this folder to the repository
3. Go to Settings → Pages → Select `main` branch
4. Your website will be live at `https://[your-username].github.io`

### Option 2: Command Line
```bash
git clone https://github.com/[your-username]/[your-username].github.io.git
cd [your-username].github.io
# Copy all files here
git add .
git commit -m "Initial website"
git push origin main
```

## File Structure
- `index.html` - Main website file
- `logo.png` - Company logo
- `gas.png` - Hero background image
- `supply.png` - About section image
- `images/` - Product images (gas cylinders)

- Responsive design for mobile/desktop
